# Hazard 7007 Android demo

A native Android Studio project using Kotlin and Jetpack Compose.

## Open and build
1. Install Android Studio (current stable).
2. Choose **Open** and select this project folder.
3. Allow Gradle sync to finish.
4. Connect an Android phone with USB debugging enabled, or start an emulator.
5. Press **Run**.

To create an APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Included
- Dark, upgraded Hazard-inspired control panel
- HILO / YELP / WAIL / STANDBY selection
- Manual demo, horn test beep, PA demo and radio UI toggle
- Output level display/slider

## Safety
This is a local sound/UI demo. It does not generate authentic emergency-vehicle sirens, transmit radio, provide public-address transmission, or control external siren hardware. The slider is a UI level control; Android media volume controls playback loudness.
